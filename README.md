## ✨ Features

- ✅ Scrape Google Maps data (name, rating, address, phone, link)
- ✅ Interactive 3D HTML output with Three.js
- ✅ Send directly to Telegram (no local files saved)
- ✅ Full screen adaptive
- ✅ Default 200 data, can choose 50/100/200/custom
- ✅ Clean terminal UI with progress bar
- ✅ 5 interactive 3D models (Icosa, Knot, Rings, Star, DNA)
